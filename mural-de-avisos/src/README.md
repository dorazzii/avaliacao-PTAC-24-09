# Mural de Avisos

Aplicação web em React em que qualquer pessoa publica um aviso com título e texto, e todos veem a lista de avisos. Os avisos podem ser editados e excluídos, formando um CRUD completo feito para a disciplina PTAC4 (IFMS).

## Como instalar e rodar

cd mural-de-avisos<br>
npm install<br>
npm run dev<br>

Depois, abra http://localhost:5173 no navegador.

## API utilizada

`https://jsonplaceholder.typicode.com/posts`
